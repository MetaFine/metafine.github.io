Adding a new policy

Plugging a new VLA backbone into MetaFine is a three-function exercise. Below is the complete, minimal evaluate.py skeleton — once your subpackage exposes these symbols, every MetaFine task graph, DR sweep, and smoothness metric works for free.

Subpackage layout

Drop a new directory under core/policies/:

core/policies/my_vla/
  pyproject.toml          # declares your subpackage + its native deps
  my_vla/
    __init__.py
    model.py              # your model class
  evaluate.py             # the 3-function contract (see below)
  train.py                # optional, but recommended

The evaluate.py skeleton

The framework imports load_model, predict, and finalize from evaluate.py — no class, no registration boilerplate. The CLI argument parsing, env construction, task-graph stepping, DR loop, and smoothness logging are all provided by utils.eval_setup.make_eval_env + utils.eval_sweep.dr_sweep. 

# core/policies/my_vla/evaluate.py
import argparse, json, torch
from utils.eval_setup import make_eval_env
from utils.eval_sweep import dr_sweep, standard_dr_sweeps
from utils.eval_metrics import EvalSummary, compute_smoothness

from my_vla.model import MyVLA

# ── 1) load_model ────────────────────────────────────────
def load_model(checkpoint_path, device):
    model = MyVLA.from_pretrained(checkpoint_path).to(device)
    model.eval()
    return model

# ── 2) predict ───────────────────────────────────────────
def predict(model, observation, instruction):
    # observation is a dict: image, state, point_cloud (if requested)
    with torch.no_grad():
        action = model.act(observation, instruction)
    return action.cpu().numpy()

# ── 3) finalize ──────────────────────────────────────────
def finalize(model):
    del model
    torch.cuda.empty_cache()

# ── CLI plumbing — same shape for every backbone ─────────
def main():
    p = argparse.ArgumentParser()
    p.add_argument("--task-graph", required=True)
    p.add_argument("--checkpoint", required=True)
    p.add_argument("--episodes", type=int, default=30)
    p.add_argument("--dr-sweep", default=None)
    p.add_argument("--smoothness", action="store_true")
    args = p.parse_args()

    model = load_model(args.checkpoint, "cuda")
    summary = EvalSummary()

    # Understanding + Behavior
    env = make_eval_env(args.task_graph)
    summary.understanding = env.run(model, predict,
                                    episodes=args.episodes,
                                    record_smoothness=args.smoothness)

    # Perception (DR-AUSC)
    if args.dr_sweep:
        summary.perception = dr_sweep(env, model, predict,
                                      sweeps=standard_dr_sweeps(),
                                      episodes=args.episodes)

    finalize(model)
    json.dump(summary.to_dict(), open("results.json", "w"), indent=2)

if __name__ == "__main__":
    main()

Install your subpackage

$ pip install -e core/policies/my_vla

Run the diagnostic eval

That's it. Your policy now plays by every MetaFine convention:

$ python core/policies/my_vla/evaluate.py \
    --task-graph configs/example_grasp_cap.yaml \
    --checkpoint checkpoints/my_vla/last.ckpt \
    --episodes 30 --dr-sweep standard --smoothness

Checklist

  • Subpackage at core/policies/<name>/ with its own pyproject.toml.
  • evaluate.py exposes load_model, predict, finalize.
  • Data path documented (LeRobot / RLDS / HDF5 / point-cloud).
  • Smoke-test a 5-episode eval on the canonical configs/example_grasp_cap.yaml.
