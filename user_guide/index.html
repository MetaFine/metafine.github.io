User Guide#

Sample of environments/robots rendered with ray-tracing. Scene datasets sourced from AI2THOR and ReplicaCAD

MetaFine is an open platform purpose-built for fine-grained manipulation research. It connects part-level interaction modeling, scalable data generation, policy training, and standardized evaluation into one end-to-end workflow for both fast iteration and rigorous benchmarking.

Why MetaFine stands out:

  • Large-scale fine-grained assets: 431 annotated objects, 1,078 annotated parts, and 4,312 grasp pose candidates for part-level manipulation research.

  • High-efficiency annotation: an open lightweight tool supports rapid custom data onboarding, with typical single-instance annotation time under 20 seconds.

  • Composable skills, expandable tasks: reusable skills can be combined to construct new tasks, and we provide 50 example tasks with 1,000 trajectories per task.

  • Cross-architecture policy support: MetaFine supports classic policy families across different architectures and can be used directly with LeRobot / StarVLA training and testing workflows.

  • Benchmark-oriented evaluation: we provide a relatively complete evaluation framework for fine-grained manipulation, emphasizing reproducibility, fair comparison, and consistent protocol design.

In short, MetaFine is not only a development platform, but also a benchmark-ready environment for measuring policy behavior on challenging fine-grained tasks.

This documentation covers installation, quickstart, data workflow, task examples, policy training templates, and evaluation setup for collaborative and reproducible research.

Contribute: we welcome bug reports, feature requests, benchmark suggestions, and code contributions. Please share issues and feedback through the project repository issue tracker and discussions.
